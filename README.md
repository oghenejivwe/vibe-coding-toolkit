# Vibe Coding Toolkit

The tools I use when building with AI, sorted by category.

## Categories

* [Design](#design)
* [Skills for Building](#skills-for-building)
* [Agents](#agents)
* [SEO](#seo)
* [Marketing](#marketing)

## Design

| Tool | What it is |
|---|---|
| [Refero Styles](https://styles.refero.design/) | Library of design systems taken from real products: colors, typography, spacing and components. Export any style as DESIGN.md, Tailwind v4 or CSS variables and hand it to an AI coding tool so the app looks designed. |

## Skills for Building

| Tool | What it is |
|---|---|
| [The Skills by Suhail Kakar](https://github.com/suhailkakar/the-skills) | 20 Claude Code skills that catch production mistakes while you build: leaked API keys, missing auth, no rate limits on LLM calls, unsafe SQL, no migration plan. Each skill fires on a specific symptom, such as adding an env var or writing an API route. |
| [SEO Launch](https://github.com/oghenejivwe/seo-skill) | My Claude Code skill for SEO from before launch onward. It reads the code to see what the product really does, researches keywords, plans the site structure, writes the pages and gates the launch. After launch it comes back on a schedule and ranks fixes by the clicks each one is worth. |

## Agents

| Tool | What it is |
|---|---|
| [The Agency](https://github.com/msitarzewski/agency-agents) | A big roster of specialist AI agents, each with its own role, workflow and deliverables: frontend developer, reality checker, Reddit community manager and many more. Installs into Claude Code, Cursor, Codex, Gemini CLI and other tools, by script or with a desktop app. |

## SEO

| Tool | What it is |
|---|---|
| [OpenSEO](https://github.com/every-app/open-seo) | Open source alternative to Semrush and Ahrefs: keyword research, rank tracking, competitor insights, backlinks, site audits and AI visibility. Comes with an MCP server and agent skills so Claude Code can pull your SEO data directly. Self host it with your own DataForSEO key and pay only for what you use, or try the hosted version at openseo.so. |

## Marketing

| Tool | What it is |
|---|---|
| [Places To Post Your Startup](https://github.com/mmccaff/PlacesToPostYourStartup) | Where to post a new product to get its first users: around 20 subreddits (r/SideProject, r/SaaS, r/indiehackers and others) plus dozens of launch directories and listing sites. Started from a Hacker News thread and still maintained; also readable at placestopostyourstartup.com. |
