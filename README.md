## Design

| Tool | What it is |
|---|---|
| [Refero Styles: Letters](https://styles.refero.design/style/04109c48-f591-4110-9739-622243d4ecc2) | Design system reference taken from Letters (letters.app). Monochrome UI, soft blue gradient hero, near black buttons, Open Runde type. Refero exports any style as DESIGN.md, Tailwind v4 or CSS variables, ready to hand to an AI coding tool. |

## Skills for Building

| Tool | What it is |
|---|---|
| [The Skills by Suhail Kakar](https://github.com/suhailkakar/the-skills) | 20 Claude Code skills that catch production mistakes while you build: leaked API keys, missing auth, no rate limits on LLM calls, unsafe SQL, no migration plan. Each skill fires on a specific symptom, such as adding an env var or writing an API route. |
